# PASOS PARA ACTIVAR VARIOS ARCHIVOS

## 1. Actualizar Supabase

1. Abre tu proyecto `portafolio-frank` en Supabase.
2. Entra a **SQL Editor**.
3. Pulsa **New query**.
4. Abre `MIGRAR_MULTIARCHIVOS.sql` de este proyecto.
5. Copia todo el contenido y pégalo en Supabase.
6. Pulsa **Run**.
7. Debe aparecer `Success`.

Esta migración conserva las actividades antiguas y convierte el archivo único anterior al nuevo formato.

## 2. Actualizar GitHub

1. Abre el repositorio `portafolio-frank-web`.
2. Sube/reemplaza los archivos de esta versión.
3. Haz **Commit changes**.
4. Espera a que GitHub Pages vuelva a desplegar.
5. Actualiza la web con `Ctrl + F5`.

## 3. Cómo publicar una actividad

1. Inicia sesión con `Frank`.
2. Selecciona curso, unidad y semana.
3. Escribe el título y la descripción.
4. Pulsa **Agregar uno o varios archivos**.
5. Para cada archivo puedes cambiar:
   - nombre visible;
   - tipo;
   - nota;
   - orden con ↑ y ↓.
6. Revisa la **Vista previa**.
7. Usa **Guardar borrador** si todavía no quieres mostrarlo públicamente.
8. Pulsa **Publicar actividad** cuando esté listo.

En la página pública, cada archivo tendrá sus botones **Ver** y **Descargar**.
