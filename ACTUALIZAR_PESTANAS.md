# Actualización: pestañas y enlaces compartidos

1. Reemplaza en GitHub los archivos de esta carpeta por los actuales.
2. Haz **Commit changes**.
3. No necesitas ejecutar SQL nuevo en Supabase.
4. En el panel de administrador crea pestañas como `Ejercicios 1.x` y `Ejercicios 2.x`.
5. Asigna cada archivo o enlace a su pestaña antes de publicar.
6. Los enlaces de Figma pueden mostrarse dentro del portafolio mediante una vista previa integrada.

Para que una vista de Figma funcione, el archivo debe estar compartido con permiso de visualización mediante enlace.
