# Actualización: enlaces de Figma

Esta versión permite agregar enlaces de Figma dentro de una actividad y organizarlos junto con los archivos.

## Uso

1. En el panel de administrador selecciona curso, unidad y semana.
2. En **Pegar enlace de Figma o de otra web**, escribe un nombre visible opcional.
3. Pega el enlace compartido de Figma.
4. Pulsa **Agregar enlace**.
5. Ordena el enlace junto con los demás archivos.
6. Guarda como borrador o publica la actividad.

En Figma, el diseño debe tener permisos de visualización apropiados para las personas con las que compartas el portafolio.

No requiere cambios adicionales en Supabase ni ejecutar SQL nuevo.
