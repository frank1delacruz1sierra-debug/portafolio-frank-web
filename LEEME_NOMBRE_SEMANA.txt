SOLUCION: ERROR DE LA COLUMNA week_title

1. Entra a tu proyecto de Supabase.
2. Abre SQL Editor y crea una consulta nueva.
3. Abre el archivo MIGRACION_NOMBRE_SEMANA.sql de este ZIP, copia todo su contenido y pégalo en el editor SQL de Supabase.
4. Pulsa Run y espera a que termine sin errores.
5. Vuelve al portafolio, recarga el administrador con Ctrl + F5 e intenta publicar la actividad otra vez.

El script agrega la columna week_title si falta y solicita recargar la caché del esquema de Supabase.
No necesitas borrar la actividad ni volver a subir los archivos para corregir este error.

Si el error continúa, confirma que ejecutaste el SQL en el mismo proyecto de Supabase que utiliza supabase-config.js y que la tabla es public.activities.
